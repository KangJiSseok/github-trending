The root script strategy must be explicit:

- root `test`: `pnpm -r --if-present test`
- root `build`: `pnpm -r --if-present build`
- optional root `lint`: `pnpm -r --if-present lint`

This keeps the manifest-only `worker` package from breaking recursive commands.
